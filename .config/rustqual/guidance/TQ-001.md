The test body contains no `assert*!` macro and no function or method calls (a
`#[should_panic]` test satisfies the rule if it invokes `panic!`).

Fix: call the code under test and assert the exact expected value or snapshot.
If the test has nothing meaningful to verify, delete it.

Note that passing `TQ-001` does not mean the test has a real assertion: rustqual
treats any function call as an implicit assertion, and accepts weak checks like
`assert!(result.is_ok())`.
Always assert the concrete output.

Don't add `assert!(true)` or an unasserted function call just to silence the
finding.

Marker, only when the user asks for one: `// qual:allow(test_quality,
no_assertion) reason: "…"` above the test.
