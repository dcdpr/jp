The same `match`, with at least three arms, appears in three or more
functions.
The finding names the matched type and doesn't name the other functions:
`just qual` lists them under `DRY / Dead Code`.

Fix: move the `match` into one method on the enum, named for what it answers
(`Status::as_str`, `Kind::is_terminal`), and call that method from each place.
A variant added later then needs one new arm.

Check the list first.
A finding on `Self` or `(unknown)` groups every `match self` rustqual couldn't
name a type for, so its functions can belong to unrelated enums.
Say so when that is the case, and leave the code.

Don't merge matches that return different things per variant into one method
with a mode parameter.

Marker, only when the user asks for one: `// qual:allow(dry, repeated_matches)
reason: "…"` above each function.
