A `match` on the same type with at least three arms appears in three or more
functions.
The finding names the matched type but not the other functions; run `just qual`
to list them under `DRY / Dead Code`.

Fix: move the `match` into a method on the enum (such as `Status::as_str` or
`Kind::is_terminal`) and call that method from each site.

Inspect the full group before refactoring.
When rustqual cannot resolve the type of `match self`, it keys the match under
`Self` or `(unknown)`, grouping unrelated enums together.
If the functions match on different types, report the false positive and leave
the code as is.

Don't combine `match` expressions that compute different properties into a
single method controlled by a mode parameter.

Marker, only when the user asks for one: `// qual:allow(dry, repeated_matches)
reason: "…"` above each function.
