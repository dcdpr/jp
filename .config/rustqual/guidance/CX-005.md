Blocks nest more than four levels deep inside the function.
The finding gives the depth and not the limit.

Fixes, in order:

1. Return early: check the failing case first and leave, so the rest of the
   function is one level shallower.
2. Use `let … else` or `?` in place of an `if let` that wraps everything after
   it.
3. Use `continue` for the items a loop skips.
4. Extract the innermost loop body or `match` into a function named for what it
   does to one item.

Don't move the nested code into a closure to hide it from the count, and don't
flatten by merging conditions into one long boolean expression.

Marker, only when the user asks for one: `// qual:allow(complexity,
max_nesting_depth=N) reason: "…"` above the function, with `N` at the current
depth.
