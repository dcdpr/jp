Block nesting inside the function exceeds the limit of 4 levels (the finding
reports only the depth).

Fixes, in order:

1. Return early on error or edge cases so the main path stays one level
   shallower.
2. Replace `if let` blocks that wrap the remainder of the scope with `let …
   else` or `?`.
3. Use `continue` to skip loop iterations early.
4. Extract the innermost loop body or `match` into a helper function that
   processes a single item.

Don't move nested code into a closure to hide it from the count, and don't
flatten branches by merging conditions into a single long boolean expression.

Marker, only when the user asks for one: `// qual:allow(complexity,
max_nesting_depth=N) reason: "…"` above the function, with `N` at the current
depth.
