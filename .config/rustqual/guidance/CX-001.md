Cognitive complexity is over 15.
The score grows with every branch and loop, and grows faster the deeper they
nest, so nesting is what to remove first.
The finding gives the score and not the limit.

Fixes, in order:

1. Return early.
   Turn `if ok { long body }` into `if !ok { return; }` followed by the body,
   and use `let … else` or `?` for a value that may be missing.
2. Use `continue` for the cases a loop skips, so the loop body isn't one `if`.
3. Extract the body of a loop or of a `match` arm into a function, when that
   step has a name worth reading.

Don't move the logic into a closure (closures aren't counted, which is the only
reason that lowers the score), don't split the function into single-use helpers
that only make sense read in order, and don't touch code the change doesn't
need.

Marker, only when the user asks for one: `// qual:allow(complexity,
max_cognitive=N) reason: "…"` above the function, with `N` at most 10% above
the current score.
