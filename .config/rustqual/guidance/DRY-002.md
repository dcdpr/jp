No production code calls this function.
Because rustqual only tracks direct calls, search the codebase for the function
name before deleting it: functions referenced as values (`static HANDLER: fn() =
handler`, clap value parsers, or serde attributes) are flagged even though they
are used.
If the function is used that way, report the false positive and leave the code
as is.

Fixes, in order:

1. Delete the function and any private helpers or types that become unused as a
   result.
2. If only tests call the function, move it into the test file (or into a
   `test_support` submodule if multiple test files share it).
3. If the function was written for a future caller, delete it and reintroduce it
   in the change that uses it.

Don't add a dummy call to keep the function alive, and don't add
`#[allow(dead_code)]`.

Markers, only when the user asks for one: `// qual:api` above a public function
of a library crate whose callers live outside the workspace, and `//
qual:test_helper` above one that only tests use.
`qual:allow` doesn't apply to this rule.
