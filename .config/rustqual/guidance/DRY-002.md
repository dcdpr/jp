No production code calls this function.
rustqual only counts calls, so search for the name before acting: a function
that is passed as a value (`static HANDLER: fn() = handler`, a clap value
parser, a serde attribute) is reported although it is used.
Say so when that is the case, and leave it.

Fixes, in order:

1. Delete the function, and whatever only it used.
2. When only tests call it, move it out of production code: into the tests
   file, or into the module's `test_support` child module when several tests
   files share it.
3. When it was written for a caller that doesn't exist yet, delete it.
   It comes back with the change that needs it.

Don't add a call to keep it alive, and don't add `#[allow(dead_code)]`.

Markers, only when the user asks for one: `// qual:api` above a public function
of a library crate whose callers live outside the workspace, and `//
qual:test_helper` above one that only tests use.
`qual:allow` doesn't apply to this rule.
