A numeric literal sits in a function body without a name.
`0`, `1`, `-1`, `2`, `0.0` and `1.0` are allowed, and so is any literal in a
`const` or `static`, in an array index, or in test code.

Fixes, in order:

1. Give the number a `const` with a name that says what it is, declared next
   to the code that uses it: above the function, or inside it when nothing else
   needs it.
   Add a doc comment when the value needs a source or a reason, such as a limit
   an API documents.
2. When the number repeats a fact the code already has, derive it: a length
   from the array, a width from the type.

Don't collect constants into a `constants` module away from their use, don't
name a constant after its value (`SIXTY`), and don't wrap the literal in a
function that only returns it.

Marker, only when the user asks for one: `// qual:allow(complexity,
magic_numbers) reason: "…"` above the function.
It covers every literal in that function.
