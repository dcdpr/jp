A function body contains an unnamed numeric literal.
`0`, `1`, `-1`, `2`, `0.0`, and `1.0` are allowed, as are literals in `const` or
`static` items, array indices, and test code.

Fixes, in order:

1. Extract the literal into a descriptive `const` next to the code that uses it
   (above the function, or inside the function if nothing else references it).
   Add a doc comment when the value comes from an external specification or
   requires rationale.
2. When the number duplicates an existing property in the code, compute it
   directly (for example, `array.len()` or `size_of::<T>()`).

Don't collect constants into a `constants` module away from their use, don't
name a constant after its value (`SIXTY`), and don't wrap the literal in a
function that only returns it.

Marker, only when the user asks for one: `// qual:allow(complexity,
magic_numbers) reason: "…"` above the function.
It covers every literal in that function.
