Two or more production functions have identical or near-identical bodies.
The finding does not name the other functions in the duplicate group; run `just
qual` to see all functions in each group under `DRY / Dead Code`.

Fixes, in order:

1. Consolidate into a single function in the module that owns the logic and call
   it from each site.
2. When the functions differ only by a value or type, parameterize the shared
   function over that difference.

If the functions live in separate crates that do not depend on each other, don't
add a crate dependency just to share a small helper; report that the duplication
crosses a crate boundary and leave the code as is.

Don't merge functions that happen to look similar but evolve independently, and
don't add a boolean or mode parameter that just switches between two unrelated
branches.

Marker, only when the user asks for one: `// qual:inverse(<other>)` on both
halves of an encode and decode pair.
`// qual:allow(dry, duplicate)` doesn't pass the gate: it suppresses the finding
in the DRY pass, but the main pass (`.config/rustqual/config.toml`) has
duplicate detection off and reports the marker as stale (`ORPHAN-001`).
