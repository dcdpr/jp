Two or more production functions have the same body, or nearly the same.
The finding doesn't name the others: `just qual` lists every function of each
group under `DRY / Dead Code`.

Fixes, in order:

1. Keep one function and call it from the other places.
   Put it in the module that owns the logic, where every caller can already
   reach it.
2. When the copies differ in a value or a type, keep one function that takes
   the difference as a parameter.

When the copies are in different crates and neither depends on the other,
sharing one means a new dependency between crates.
Don't add one for a small helper: say that the duplicate crosses a crate
boundary.

Don't merge functions that are alike today and change for different reasons,
and don't add a parameter that only selects between two unrelated bodies.

Marker, only when the user asks for one: `// qual:allow(dry, duplicate) reason:
"…"` above each function, or `// qual:inverse(<other>)` on both halves of an
encode and decode pair.
