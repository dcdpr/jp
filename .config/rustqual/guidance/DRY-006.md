Nothing in the workspace refers to this struct, enum, type alias, `const` or
`static`.
A type's own `impl` blocks don't count as a use, and being `pub` doesn't
either.

Search for the name before acting.
A `static` that a macro registers, such as a handler under
`#[distributed_slice(HANDLERS)]`, is reported although the linker uses it.
Say so when that is the case, and leave it.

Fixes, in order:

1. Delete the item, its `impl` blocks, and whatever only they used.
2. When only tests use it, move it into the tests file or the module's
   `test_support` child module.

Don't add a reference to keep it alive, and don't add `#[allow(dead_code)]`.

Markers, only when the user asks for one: `// qual:api` above a public item of
a library crate that is used from outside the workspace, and `//
qual:test_helper` above one that only tests use.
`qual:allow` doesn't apply to this rule.
