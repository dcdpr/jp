Nothing in the workspace references this `struct`, `enum`, `type` alias,
`const`, or `static`.
A type's own `impl` blocks and `pub` visibility do not count as references.

Search the codebase for the item's name before deleting it.
A `static` registered by a macro (such as `#[distributed_slice(HANDLERS)]`) is
consumed by the linker at build time and flagged as unused by rustqual.
If the item is used that way, report the false positive and leave the code as
is.

Fixes, in order:

1. Delete the item, its `impl` blocks, and any private helpers or types that
   become unused as a result.
2. If only tests reference the item, move it into the test file (or into a
   `test_support` submodule if multiple test files share it).

Don't add a dummy reference to keep the item alive, and don't add
`#[allow(dead_code)]`.

Markers, only when the user asks for one: `// qual:api` above a public item of a
library crate that is used from outside the workspace, and `// qual:test_helper`
above one that only tests use.
`qual:allow` doesn't apply to this rule.
