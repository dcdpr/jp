# Wiki

What JP knows about itself: how the system works today, the words the project
uses, and the research behind its designs.
A Reference page describes the system as it is, and changes with it; a Snapshot
is dated research that doesn't.

## Start here

- [Architecture] is how JP is built, starting from how a `jp query` turn runs.
- The [Glossary] holds the exact terms code, docs, and commits use for each
  concept.
- [Guides] walk through tasks that come up while working on JP.
- [Research] holds the studies behind JP's designs.

Write a ticket for work to do, an RFD for a decision to make, and a wiki page
for what is known.
[All pages] lists every page, archived ones included.
